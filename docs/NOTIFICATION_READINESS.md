# 알림 상태 점검 · 모바일 설치

## 구현 범위
- 알림 메뉴 상단에 기기 환경, 브라우저 권한, 계정에 연결된 현재 구독의 일정 수신 설정, 자동 발송 서버 상태를 분리한다.
- 단순 조회는 권한 요청, 구독 생성, 수신 설정 변경, 테스트 발송을 수행하지 않는다.
- 첫 조회/30초/포커스/화면 복귀/온라인 상태 변화 때 다시 읽는다. 오류·미지원·iOS 일반 탭·차단·로그인 만료를 켜짐/꺼짐과 구별한다.
- 조회는 10초 뒤 실패로 전환한다. 설정 변경 직전 기존 조회를 취소하고, 요청 식별자로 늦은 결과의 덮어쓰기를 막는다.
- 설정 완료는 수신 보장이 아니다. 테스트 발송 요청 수락, 실제 기기 표시, 사용자 확인을 구별한다.
- 내 일정 선택 후 즉시 또는 약 2분 뒤 기존 테스트 API를 이용한다. 테스트는 자동 수신 동의를 켜지 않는다.
- 기존 서비스 워커의 알림 열기/명시적 확인/미루기는 유지한다. 오프라인 캐시나 오프라인 편집은 추가하지 않는다.

## 설치
- manifest, 192/512 PNG와 Apple 180 PNG, standalone/Apple 메타데이터를 제공한다.
- 기존 비공개 접근 정책을 유지한다. 인증된 manifest 요청을 위해 link에 `crossOrigin="use-credentials"`를 지정한다. manifest나 설치 안내를 추가했다고 공개 가입 또는 외부 접근이 열리는 것은 아니다.
- 브라우저의 실제 beforeinstallprompt가 있을 때만 설치 버튼을 노출한다. 안내를 읽거나 프롬프트를 수락한 것만으로 설치 완료라 하지 않는다.
- iPhone/iPad는 Safari 공유 → 홈 화면에 추가 → 아이콘으로 열기 → 필요시 재로그인 → 알림 수신 켜기 순서다.
- Android와 PC/Mac 수동 메뉴 안내도 제공한다. 설치는 알림 허용과 별도이며 메뉴는 OS/브라우저 버전에 따라 달라질 수 있다.
- 근거: https://webkit.org/blog/13878/web-push-for-web-apps-on-ios-and-ipados/ 및 https://developer.mozilla.org/en-US/docs/Web/Progressive_web_apps/Guides/Making_PWAs_installable

## 검증 범위
- `scripts/test-notification-diagnostics.mjs`: 상태 판정, 읽기 전용 조회, 오류·만료·타임아웃, 권한 복귀, 변경 경쟁 상태, SSR 문구/레이블, manifest와 PNG 크기.
- 기존 일정·알림 회귀 테스트도 실행한다. 테스트는 격리된 데이터/모의 푸시를 사용한다.
- 실제 iPhone/Android 설치, 잠금/브라우저 종료 후 수신, 집중 모드, 제한된 네트워크는 실제 기기에서 별도 검증해야 한다. 자동 테스트 성공을 실제 수신 검증으로 간주하지 않는다.
