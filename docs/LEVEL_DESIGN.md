# J에게 — 50레벨 성장 기록

2026-09-20. 기존 P→J 성장 곡선 위에 표시 전용 챕터·레벨 이름·칭호·배지와 완료 피드백을 추가한다.

## 변경하지 않는 규칙

- `lib/progression.ts`의 임계값이 유일한 기준. 총 50레벨, 12,000 XP에서 J. 하루 전체 상한 60 XP, 이론상 최단 200일.
- 계획 첫 완료 10 XP, 준비 첫 완료 3 XP, 오늘 목표 보너스 10 XP. 남은 한도만큼만 지급되며 칭호·배지는 추가 XP를 지급하지 않는다.
- 단계는 1~10 P, 11~20 P+, 21~35 PJ, 36~49 J−, 50 J. 챕터와 단계는 별개이며 49레벨을 J로 표시하지 않는다.
- 기존 완료·취소·삭제·중복 방지·한국 시간·목표 잠금·실천일 계산과 과거 XP를 그대로 유지한다. 데이터베이스 및 마이그레이션 변경 없음.

## 10개 챕터와 칭호

각 챕터는 5개의 고유 레벨 이름을 제공한다. 챕터 마지막 레벨에 도달하면 칭호를 획득한다. 정확한 레벨명은 `lib/growth-journey.ts`에 정의한다.

| 레벨 | 챕터 | 마지막 레벨 칭호 |
| --- | --- | --- |
| 1–5 | 첫 페이지 | 첫 장을 연 사람 |
| 6–10 | 작은 약속 | 약속 지킴이 |
| 11–15 | 하루의 리듬 | 리듬 메이커 |
| 16–20 | 준비의 여유 | 준비의 달인 |
| 21–25 | 나만의 방식 | 나만의 플래너 |
| 26–30 | 꾸준함의 힘 | 꾸준한 실천가 |
| 31–35 | 계획과 실행 | 실행 설계자 |
| 36–40 | 하루의 설계 | 하루의 설계자 |
| 41–45 | 나답게 이어가기 | 균형 있는 계획가 |
| 46–50 | J에게 도착 | 나만의 J |

칭호는 성장 이야기이며 실제 행동 유형을 측정한 자격이나 MBTI 성격 평가가 아니다. 유용한 일정 기능을 레벨로 잠그지 않는다.

## 사용자에게 보이는 흐름

1. 오늘의 성장 카드: 현재 단계·레벨·이름, 다음 레벨까지 남은 XP와 오늘 목표·진척·일일 XP만 표시한다. 설명 전문, 챕터·칭호·배지 목록은 메인에 렌더링하지 않는다.
2. 카드의 ‘성장 상세’와 사이드바 성장 기록은 `/growth`로 이동한다. 일정이 0개이거나 일정 조회가 실패해도 성장 카드는 유지한다. ‘오늘로’는 `/#growth-record`로 돌아오며 로딩 전후 유지되는 성장 카드에 스크롤·포커스를 복원한다.
3. 목표가 잠기면 ‘첫 완료 후 고정’만 짧게 표시하고 `/growth#daily-goal-guide`에서 이유를 읽을 수 있게 한다. 로딩·오류·재시도·일일 XP 상한 상태는 메인에도 남긴다.
4. 상세의 다음 칭호: 획득 레벨과 필요한 남은 XP. 현재 레벨 진행률과 칭호 목표를 구분한다.
5. 상세의 성장 여정: 열면 10개 챕터를 자유롭게 선택하여 각 5레벨의 이름·정확한 누적 XP·도달/현재/미도달 상태를 확인한다. ‘내 위치로’로 돌아온다.
6. 상세의 실천일 배지: 1일 ‘첫 발자국’, 7일 ‘일곱 번의 약속’, 30일 ‘서른 날의 기록’, 100일 ‘백일의 꾸준함’. 누적 실천일이며 연속 출석이 아니다. 목표 고정·보너스·상한·취소 시 XP 유지 규칙도 상세에 보존한다.
7. 50레벨 이후: 모든 칭호를 획득한 상태, 레벨 50 유지, XP·실천일 기록 계속. 51레벨이나 없는 보상을 제안하지 않는다. 상세 진입 자체로는 완료·경험치를 지급하지 않는다.

## 보상 피드백과 접근성

- 서버의 완료 저장이 성공하고 해당 행동의 `awardedXp`가 양수인 경우만 화면 보상 안내를 표시한다. 조회·새로고침·목표 설정·취소·실패·재완료/상한의 0 XP에는 레벨업 안내를 재생하지 않는다.
- `awardedXp`는 목표 보너스를 제외한 행동 보상이다. ‘계획/준비 완료 +N XP’로 표시하고, 목표 달성은 별도 문구로만 안내한다.
- 직전 요약을 모르면 새 레벨/칭호/배지 획득을 추측하지 않는다. 잠금해제 기록은 서버 누적값에서 파생하며 별도 로컬 저장을 만들지 않는다.
- 일반 기능을 막는 팝업·소리·추가 푸시·자동 권한 요청은 없다. 사용자가 닫을 수 있는 화면 안내만 사용한다.
- 상태는 색 외에 글자로도 표시한다. 버튼·summary 키보드 접근, 현재 레벨 `aria-current`, 부드러운 상태 알림, 동작 줄이기 설정을 지원한다.
- 기존 Forest & Paper 색에 짙은 녹색 성장 카드와 금색 획득 표시를 더한다. 이미지 생성이나 새로운 외부 서비스를 연결하지 않는다.

## 검증

사용성 테스트에서 50개 임계값 전후, 모든 단계/챕터 경계, 0·12,000·상한 이후 XP, 1/7/30/100일 배지, 부분 XP 지급, 목표 동시 달성과 반복 안내 방지를 검증한다. 기존 성장·일정·알림 통합 테스트는 격리된 데이터와 모의 푸시로 유지한다. 실제 브라우저 테스트는 별도 요청 시 실행한다.
