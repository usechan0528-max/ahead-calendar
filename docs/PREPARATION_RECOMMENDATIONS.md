# 맞춤 준비 추천

일정 상세 → 준비 → 맞춤 준비 추천에서 사용한다. Forest & Paper 색상, 16px 제목, 14px 설명, 44px 터치 영역을 유지한다.

## 현재 제공하는 기능

- 생일/생신, 결혼/연애 기념일, 기타 기념일, 결혼식 참석, 행사/공연, 여행, 회의, 마감, 야외 활동, 일반 일정의 10가지 준비 목적. 기존 최상위 일정 종류 4개는 유지한다.
- 자동 모드에서는 제목의 키워드와 일정 종류로 목적을 추정한다. 사용자가 목적을 직접 선택할 수 있으며 선택은 일정별로 저장한다.
- 장소, 저장된 이동 계획, 여러 날 일정 여부에 따라 준비를 추가한다. 각 추천에 이유와 권장 시점을 보여준다.
- 준비 목록에 담기, 숨기기, 숨긴 추천 복원. 알림 추가는 별도 선택이며 기존 알림 API/동의 체계를 사용한다.
- 외부 AI 호출, 가격/예약 조회, 음력 날짜 변환을 하지 않는다. 실제 경로는 지도 기능에서 확인한다. 날씨 조회와 날씨 확인 추천은 제공하지 않는다.

## 날짜와 저장 의미

일정 생성·수정 폼 또는 상세에서 ‘준비 항목 사용’을 끌 수 있다. `events.preparations_enabled`에 일정별로 저장하며 반복 회차 전체에 적용된다. 끄면 체크리스트, 맞춤 추천, 준비 개수, 준비 안내 배너와 모아보는 준비 목록에서 제외한다. 일정·지도·알림은 그대로 이용한다.

기존 항목과 완료/XP/추천 기록은 삭제하지 않는다. 다시 켜도 템플릿을 추가로 생성하지 않는다. 처음부터 꺼서 생성한 일정은 기본 준비 항목을 만들지 않는다. 상세 토글은 알림 버전을 변경하거나 예약을 취소하지 않는 별도 API를 사용한다. 새 필드를 보내지 않는 구버전 수정 요청은 기존 표시 설정을 유지한다.

한국 시간의 현재/다음 회차를 사용한다. 종일 일정은 사용자가 정한 알림 기준 시각을 사용한다. 이전 권장 시점이라도 준비는 담을 수 있지만 지난 시점의 추천 알림 버튼은 제공하지 않는다.

반복 일정의 준비 목록/목적/숨김/알림 설정은 일정 전체에 적용된다. 완료 체크와 경험치는 기존 회차별 시스템이 담당한다. 채택만으로 완료·XP·푸시 작업이 생성되지 않는다.

채택한 항목의 제목과 준비 시점은 독립적인 사용자 메모다. 이후 목적이나 일정이 바뀌어도 덮어쓰지 않는다. 알림은 상대 시간 규칙으로 저장되며 이후 회차에도 적용된다.

## 중복과 동시성

- 서버 카탈로그의 안정적인 규칙 ID만 허용한다. 클라이언트가 준비 제목이나 시점을 임의로 전달할 수 없다.
- `preparation_items(event_id, recommendation_key)`와 `recommendation_state(event_id, rule_key)` 고유 제약, D1 배치 트랜잭션으로 중복 채택을 방지한다.
- 기본 항목/수동 항목은 알려진 동등 제목으로 연결한다. 편집된 채택 항목도 원래 ID를 유지한다. 임의의 의미 유사성을 판별하는 AI 중복 검사는 아니다.
- 삭제 후 재채택으로 새 준비 ID가 만들어지는 것을 막기 위해 채택 기록을 보존한다. 기본/수동 동등 항목도 삭제 시 알려진 규칙에 삭제 기록을 남긴다. 삭제된 추천을 복원 버튼으로 다시 채택할 수는 없다. 필요하면 직접 준비 항목을 추가할 수 있다.
- 이벤트/목적 수정 버전과 기준 회차 토큰을 검사한다. 다른 탭의 변경으로 오래된 요청이면 409와 새 추천을 반환한다. 이미 저장된 채택은 이후 목적 변경과 관계없이 원래 준비 항목을 반환한다.
- 모든 조회/쓰기는 기존 소유자 인증과 일정 소유권을 적용한다. GET은 데이터 쓰기를 하지 않고 캐싱을 금지한다.

## 검증

빌드 후 `npm run test:recommendations`. 별도 메모리 D1에서 전체 마이그레이션을 적용하고 실제 Worker API를 검증한다. 외부 네트워크 차단으로 실제 사용자 데이터와 푸시에 영향을 주지 않는다. 기존 customization/event-duration/progression 테스트도 함께 실행한다.

마이그레이션 0016은 새 추천 설정/채택 기록 테이블과 nullable 출처 열만 추가하며 기존 일정, 준비, 알림, XP를 변경하지 않는다.

## 후속 확장 경계

2026-09-20 날씨 기능 제거: `location-weather`는 더 이상 추천하거나 채택하지 않는다. 여행 짐 싸기와 야외 활동 대안은 일반 준비 문구로 안내한다. 기존 준비 항목·완료·XP·알림은 삭제하거나 이름을 바꾸지 않는다. 이전 제목 별칭과 규칙 ID는 중복 채택 및 삭제 이력 보호를 위해 유지한다. 데이터 마이그레이션은 없다.

예산·동행자·선호를 받는 개인화와 추천 품질 피드백은 별도 단계다. 외부 상품/예약 정보와 AI 서비스 연동은 제공 범위·동의·비용·출처·오류 처리를 먼저 정해야 한다.
